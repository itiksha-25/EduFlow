# EduFlow - Academic Management System

## Overview

EduFlow is a Java-based academic management system that helps manage student attendance and examination schedules.

The application provides attendance calculation, exam eligibility checking, attendance analysis, exam scheduling, and basic exam conflict detection through a simple command-line interface.

## Features

### Student Management
- Add new students
- Automatically generate student IDs
- View student details
- Store department information

### Attendance Management
- Update student attendance
- Calculate attendance percentage
- Check examination eligibility
- Validate attendance input
- Store attendance data

### Attendance What-If Calculator
- Calculate current attendance
- Find the number of classes required to reach 75% attendance
- Show expected attendance after attending the required classes

### Attendance Report
- Total number of students
- Average attendance
- Number of eligible students
- Students below 75%
- Highest attendance
- List of students below 75%

### Exam Management
- Add examinations
- View examination schedule
- Store subject, date, time and room
- Validate date and time input
- Detect room and time conflicts

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList / Collections
- File I/O
- Exception Handling
- Command Line Interface

## Requirements

- Java JDK 8 or later
- Command Prompt or terminal

No external libraries or database installation is required.
